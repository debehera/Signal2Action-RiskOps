# Environment Variables & Configuration (`.env`)

| Variable Name | Description | Example Value |
| :--- | :--- | :--- |
| `DATABASE_URL` | SQLAlchemy connection string for PostgreSQL | `postgresql://user:password@localhost:5432/riskops` |
| `API_V1_STR` | Prefix for API routes | `/api/v1` |
| `PROJECT_NAME` | Name of the application | `Signal2Action RiskOps` |
| `ENVIRONMENT` | Deployment environment | `development` |
